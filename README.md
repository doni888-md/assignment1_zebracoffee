# Zebra Coffee — Multi-Page Semantic HTML Website

An educational multi-page web application built strictly with semantic HTML5 for the Zebra Coffee chain branch located at Mangilik El 38 Avenue in Astana, Kazakhstan.

## Project Overview

The objective of this assignment is to design and implement a clean, accessible, and standards-compliant multi-page website without external CSS styling or JavaScript logic. The project emphasizes strict document hierarchy, semantic structural landmarks, proper table modeling, and complete native form validation.

## Website Structure

The project consists of eight interconnected semantic pages:

* `index.html` — Landing portal introducing the branch concept, quick navigation, and operational highlights.
* `about.html` — Brand history, service benchmarks operational table, and core corporate principles.
* `career.html` — Employment opportunities, barista duty requirements, and an interactive job application form.
* `menu.html` — Full beverage catalog featuring detailed pricing data tables and categorized drink options.
* `reviews.html` — Verified customer feedback citations and an interactive review submission form.
* `booking.html` — Seating reservation form with full input constraint validation and table preference options.
* `contacts.html` — Contact channels, semantic address metadata, weekly operating schedule, and external map link.
* `colophon.html` — Technical documentation page outlining HTML semantics, project metadata, and site architecture.

## Key Technical Features

* **HTML5 Semantic Landmarks:** Consistent use of `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>` across all documents.
* **Uniform Navigation:** Synchronized eight-link navigation scheme linking every document without broken routes.
* **Data Representation:** Fully accessible tables utilizing `<caption>`, `<thead>`, `<tbody>`, `<th scope="col">`, and `<th scope="row">`.
* **Client-Side Form Validation:** Functional native browser verification using dedicated input types (`text`, `email`, `tel`, `number`, `date`, `time`, `radio`, `checkbox`) and attributes (`required`, `min`, `max`).
* **Accessibility:** Descriptive image alternative text (`alt`), `<figure>`/`<figcaption>` groupings, and semantic definition lists (`<dl>`).
