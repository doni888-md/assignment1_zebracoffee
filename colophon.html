About This Website

This website was created as an educational project about Zebra Coffee in Astana. The website provides information about the coffee shop, its menu, visitor reviews and other useful information.

The website was created using basic HTML. CSS and JavaScript are not used because this stage of the project focuses on HTML structure and semantic elements.

HTML Structure

Semantic Elements

The website uses semantic elements such as header, nav, main, section, article, aside and footer.

These elements were chosen because they describe the purpose of different parts of the page and make the structure easier to understand. 

<header>
    <nav>
        <ul>
            <li>Home</li>
            <li>Menu</li>
            <li>Reviews</li>
        </ul>
    </nav>
</header>

Working With the Pages

All pages are connected with relative links. This allows visitors to move between the pages without using external website addresses.

The pages are stored in the same project folder, so the relative links can connect the files locally.

The Cmd key can be used with other keyboard commands while working with files on a Mac computer.

A web browser reads the HTML structure and displays the content of each page.

Forms and Browser Behavior

Review Form

The Reviews page contains a form where visitors can enter information such as their name, email, phone number, visit date, rating and review.

The form uses elements such as input, select and textarea.

When the user submits the form, the browser tries to process the information according to the action and method attributes.

At the moment, the form does not send information to a real server because server-side handling will be added later.

A browser can display a message such as Form submission completed when a real server processes the form.

Additional HTML Elements

Why Semantic HTML Is Used

Semantic HTML helps organize information clearly. For example, an article can contain a separate piece of information, while an aside can contain additional content.

The website also uses lists, tables, images and links to present information in different ways.
